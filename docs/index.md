# sphinx-skos

sphinx-skos is a Sphinx extension that builds SKOS vocabulary files into a documentation site,
with one page for every vocabulary, concept and collection. Start with the guide that matches
what you need.

- [How-to guides](how-to/index.md): publish your vocabulary files as a site, give it a
  ready-made layout, and deploy it to GitHub Pages.
- [Reference](reference/index.md): the settings the extension adds to `conf.py`, the RDF
  copies it writes and the workflow that builds a site on GitHub.

For people who work on sphinx-skos itself, see
[CONTRIBUTING.md](https://github.com/FAIR-DM/sphinx-skos/blob/main/CONTRIBUTING.md) and
[CONSTITUTION.md](https://github.com/FAIR-DM/sphinx-skos/blob/main/CONSTITUTION.md).
